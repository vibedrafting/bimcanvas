# Web 布局改造指导文档

> [!IMPORTANT]
> **用户需求汇总**
> - **布局**：必须是响应式的（适应浏览器窗口大小），不能是固定的最大尺寸。
> - **命令**：“修改”类命令（移动、镜像、删除）应放在单独的“Ribbon 风格”选项卡中，并带有图标。
> - **数据加载**：将“Load Room/Proposal”合并为一个“加载示例数据”按钮。
> - **品牌形象**：去除“Calm Tech”，打造“大厂”成熟产品的质感。
> - **图层管理器**：修复下拉列表对齐问题（向右下方展开）并实现“点击外部关闭”。
> - **撤销/重做**：做得更小、更自然。
> - **画廊**：修复位置尴尬的问题。

## 第一阶段：响应式基础（布局引擎）

**目标**：放弃顶层布局的绝对定位，转而采用结构化的 CSS Grid/Flexbox 方法。这确保了 UI 能适应任何屏幕尺寸。

### [MODIFY] `src/layouts/MainLayout.vue`
-   **当前**：绝对定位 (`top: 0, left: 0`)。
-   **新方案**：CSS Grid 布局。
    ```css
    .main-layout {
      display: grid;
      grid-template-areas:
        "header header header"
        "gallery canvas properties";
      grid-template-columns: auto 1fr auto; /* 画廊和属性面板自动宽度，画布填充剩余空间 */
      grid-template-rows: auto 1fr; /* 头部自动高度，内容填充剩余空间 */
      width: 100vw;
      height: 100vh;
    }
    ```
-   **收益**：“画廊”和“属性”面板将挤压画布（或者如果首选悬浮，则覆盖在画布之上，但结构更清晰），而不是尴尬地漂浮。

## 第二阶段：导航与命令组织（Ribbon 风格）

**目标**：实现类似 Revit 但更现代化（Linear/Apple 风格）的选项卡式命令界面。

### [NEW] `src/components/UI/RibbonToolbar.vue`
-   用新的 `RibbonToolbar` 替换 `CanvasToolbar.vue`。
-   **结构**：
    -   **顶部栏 (快速访问)**：
        -   品牌标识（BIMCanvas）。
        -   **撤销/重做**：改为**纯图标**按钮（无文字），更紧凑自然。
        -   文件菜单（加载示例）。
    -   **选项卡栏**：“常用 (Home)”（选择、基础）、“修改 (Modify)”（移动、旋转、镜像、删除）、“视图 (View)”。
    -   **上下文选项卡**：当选中对象时，自动切换到或高亮显示“修改”选项卡。

### [MODIFY] `src/components/UI/CanvasToolbar.vue` (废弃或重构)
-   **加载按钮**：将两个按钮合并为单个 `GlassButton` “加载示例”（默认加载带家具数据）。
-   **修改命令**：将 `Rotate`、`Move`、`Delete` 移动到新的“修改”选项卡/区域，使用 SVG 图标。

## 第三阶段：组件细节优化

**目标**：修复针对特定组件的 UX 痛点，遵循 KISS 原则。

### [MODIFY] `src/components/UI/ViewControls.vue` (新组件或集成在 Toolbar)
-   **位置调整**：将“图层管理器”按钮移动到 **“Human”/“AI Vision” 视图切换按钮旁边**。
-   **样式优化**：图层按钮改为**纯图标**形式（如“图层”或“设置”图标）。
-   **功能保持**：
    -   保留现有的下拉列表逻辑（Grid, Labels, Bounds 等）。
    -   **修复交互**：下拉列表应向**右下方**展开，并实现“点击外部关闭”功能。

### [MODIFY] `src/components/UI/SideGallery.vue`
-   **布局集成**：不再使用 `position: absolute`，而是作为 `MainLayout` 中的一个网格项。
-   **行为**：可折叠侧边栏。展开时，它会挤压画布（或以毛玻璃背景覆盖）。

### [MODIFY] `src/components/UI/base/GlassButton.vue`
-   **样式**：优化“撤销/重做”为纯图标或极简文字。
-   **视觉**：移除“Calm Tech”徽章。将品牌更新为“BIMCanvas”，使用干净、现代的字体（Inter/SF Pro）。

## 第四阶段：视觉打磨（“大厂”质感）

**目标**：提升美学标准以匹配“设计哲学”。

-   **主题**：深邃、丰富的暗色模式（`#0a0a0f`），带有微妙的边框（`rgba(255,255,255,0.08)`）。
-   **排版**：强制使用 `Inter` 或系统无衬线字体。
-   **反馈**：添加微妙的悬停状态和激活状态（除非必要，否则不要使用“发光”）。

## 验证计划

### 手动验证
1.  **响应式测试**：调整浏览器窗口大小。验证头部停留在顶部，画廊在侧边，画布填充剩余空间且无滚动条。
2.  **Ribbon 测试**：点击“修改”选项卡。验证移动/镜像/删除图标是否出现。
3.  **图层管理器测试**：
    -   点击图层管理器按钮。验证列表向*右*展开。
    -   点击画布（列表外部）。验证列表*关闭*。
4.  **加载测试**：点击“加载示例”。验证带家具的场景是否加载。

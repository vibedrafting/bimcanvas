    分区设计的本质

    分区不只是"空间太复杂，先切小再处理"。它有三层递进的价值，每一层都不可或缺。

    ⚙
    工程价值：约束解耦
    25㎡ 卧室中，床/衣柜/书桌/梳妆台的约束互相耦合，是高维优化问题。
    分区后每个子空间聚焦单一功能，约束大幅解耦。

    这是最容易被看见的价值，但也是最浅的。
    ✨
    质量价值：创造设计语言
  • 分区赋予空间以意图 — "更衣区"三个字激活关于这类空间的全部设计常识
  • 家具属于功能叙事 — 家具间关系有了上下文，不再是散落的独立对象
  • 留白是有意识的节奏 — 区域间的留白不是"剩余空间"，而是呼吸感

    • "有设计感"和"只是塞满了"的区别，就在于空间是否有意图。
    🤝
    过程价值：最早的对齐点
    分区图本身就是交付物 — 用户几秒内判断设计方向是否正确。
    调整分区方案的成本，远小于推翻整套家具布置。

    分区让"我理解你的需求了吗？"有了具体、可评估的载体。

    核心认知：分区、过道、家具预布置 — 一体三面

    # 设计师脑中的真实思维过程（三件事同时发生） 家具预布置 "这里需要多大的空间？" → 空间需求 过道设计 "人怎么在家具之间移动？" → 空间连接 分区 前两者叠加后浮现的空间结构 → 空间组织 家具是岛屿，过道是河流，分区是看着岛屿和河流之后画出的地图。 你不能先画地图再造岛屿。分区线是结论，不是前提。 # 双向锁定 预布置（粗略想象）→ 浮现分区结构 → 分区锁定空间策略 → 指导精确布置 ↑ | ←———— 如果放不下，回来调整 ←—————————————

    分区前是发散的探索 — "床放这里行不行？那里呢？"
    分区后是收敛的执行 — "睡眠区已定，在这个范围内把床放好。"

    分层评价体系

    从一个卫生间选墙错误中发现的系统性缺失：我们定义了"什么不能做"，但没有定义"什么是做得好"。

    Layer 1 工程合规 "这个布局有没有错？" 以不出错为底线 Layer 2 设计品质 "这个布局好不好？" 以好设计为目标 Layer 3 设计倾向 "这个布局符不符合业主喜好？" （未来） Layer 4 经济指标 "这个布局花多少钱？" （未来） 每层是上一层的前提 — 有错误的布局谈不上品质，层次之间不可跳跃。
    Layer 1：工程合规（二元判断）
  • 几何合法 — 不越界/不穿墙/不占柱/不侵禁区/不重合
  • 通行可达 — 主通道≥900mm，所有功能点从入口可达
  • 功能完整 — zone.tags 每个功能至少有一个对应模块

    • 由 validate_layout 自动检查 + Agent 功能完整性比对
    Layer 2：设计品质（连续光谱）
  • 动线设计 — 入门流线直觉、功能序列递进、无折返
  • 空间意图 — 每个区域有明确的功能主题，无无意图死角
  • 功能叙事 — 同面墙的家具讲述连贯故事，群组协调
  • 空间节奏 — 入口到深处隐私梯度、密度渐变、有意识留白
  • 采光通风 — 光路通畅、功能-光匹配、通风不被阻断
    • 核心认知：品质标准就是设计目标
    好的设计不是碰巧的 — 人类设计师画卫生间时，不会先随便选一面墙放台盆、画完再检查动线自然不自然。
    品质标准贯穿全流程：理解阶段是空间阅读的透镜 → 策略阶段是显式声明的设计目标 → 执行阶段是每个决策的判据 → 审查阶段是目标达成的验证。
    从"规则驱动"到"目标驱动"：规则告诉 Agent"不要做什么"（护栏），目标告诉 Agent"要追求什么"（驱动力）。两者缺一不可，但目标是方向，规则是边界。

    语义方案驱动的渐进式工作流

    设计过程的本质是熵减 — 每做一个决定，可能性空间就缩小一些。
    语义方案让熵减过程可见、可锚定、不可逆转。

    # 熵减过程 高熵（无穷可能） 低熵（唯一方案） "空房间" → "床靠西墙" → "衣柜北墙" → "梳妆台延伸区" → 精确坐标 ↓ 可能性骤降 ↓ 进一步收窄 ↓ 接近确定 ↓ 完全确定 # 当前问题：熵减在 thinking block 内部 — 不可见、不可恢复、不可锚定 # 新方案：每做一个决定就写入语义方案 — 可见即不可逆转，决策链条清晰可见
    📝
    渐进外化：v0.1 → v0.2 → v0.3
  • v0.1 空间骨架 — 动线+纵深+采光+初步意图（不涉及家具）
  • v0.2 主体框架 — 主要家具墙面归属+分区结论+设计目标
  • v0.3 完整方案 — 可选家具+设计目标细化+全部确认

    • 每次更新仅 5-10 行增量，物理上不可能触发 32K 截断。
    🔄
    关键决策：家具先于分区
  • 家具位置由物理约束决定（墙面长度、门窗位置）
  • 物理事实不因概念分区而改变 — 西墙永远是最长实墙
  • 用家具位置反向过滤分区方案，而非在分区内布置家具
  • 约束方向：物理空间 → 家具位置 → 过滤分区（单向，无循环）
    • ⚡
    结构性提速
  • 语义方案拆分输出 — 消除 32K 截断重来（~5 min）
  • 顺序反转 — 搜索空间从"评估所有分区"降为"过滤不兼容的"（~5 min）
  • 预处理墙面数据 — 消除重复空间分析 3→1 次（~8 min）
  • Layer 分离 — Stage 3 只管合规，Stage 4 只管品质

    • 目标：27 min → 10-14 min（首次写入从第 25 分钟提前到第 7-9 分钟）

    Git Worktree 并行隔离

    多房间场景下，MainAgent 并行派发多个 layout-agent，每个在独立 Worktree 中工作，互不干扰。

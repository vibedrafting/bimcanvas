## 一、设计原则

| 规则 | 说明 | 适用家具 |
|------|------|----------|
| **靠墙规则** | 大型家具尽量靠墙放置 | 衣柜、床、沙发、书柜 |
| **居中规则** | 某些家具应居中于墙面 | 电视柜居中于电视墙、床居中于床头墙 |
| **顶角规则** | 大型家具无法填满整面墙时，优先贴靠实墙角，将剩余空隙留在门口/通道一侧——窄缝（< 600mm）积灰难清洁，形成卫生死角 | 衣柜、储物柜、书柜、鞋柜 |
| **朝向规则** | 家具背面靠墙，正面朝向空间中心 | 沙发背墙面向客厅、床头靠墙 |
| **对位规则** | 相关家具形成对位关系 | 沙发正对电视、餐椅围绕餐桌 |
| **避窗规则** | 避免家具阻挡采光（淋浴房除外） | 床头不靠窗、书桌侧对窗 |
| **避门规则** | 不阻挡门的开启范围 | 所有家具 |
| **异形利用规则** | 异形空间（L形拐角、凹位、延伸区）的墙面必须纳入衣柜候选墙面评估；评估后未选为衣柜墙的残余墙面，应优先用于辅助家具，避免闲置 | 衣柜、梳妆台、斗柜、边几 |

## 二、布置优先级

```
1. 锚点家具 → 确定设计区的核心定位
2. 主要家具 → 围绕锚点布置
3. 辅助家具 → 填充剩余空间
```

| 房间 | 锚点家具 | 主要家具 | 辅助家具 |
|------|----------|----------|----------|
| 客厅 | 电视柜 | 沙发 | 茶几、边几、落地灯 |
| 主卧 | 床 | 衣柜、床头柜 | 窗帘、梳妆台、斗柜 |
| 次卧 | 床 | 衣柜、床头柜 | 窗帘、书桌 |

> **次卧衣柜说明**：衣柜是卧室储物核心，次卧中应与床同步规划（阶段 A 主要家具）。仅当所有墙面放置 600mm 深柜体后主通道 < 600mm 时才允许省略。
| 餐厅 | 餐桌 | 餐椅 | 餐边柜 |
| 书房 | 书桌 | 书柜 | 椅子、台灯 |

## 三、空间约束

Agent 布置时必须满足以下硬性约束：

```
1. bounds 必须完全在 Zone.innerBoundary 内
2. bounds 不能与任何 exclusionAreas 重叠
3. bounds 不能与其他已放置 modules 重叠
4. 不能阻挡门的开启范围（门扇弧线区域）
```

> **重要：无需考虑墙面完成面**
> `Zone.innerBoundary` 已经是扣除完成面厚度后的净空边界。AI 布置家具时直接以 `innerBoundary` 为可用范围即可，**不需要**再额外预留完成面空间。重复扣减会导致可用空间被不必要地缩小。

## 四、尺寸标准

### 4.1 通道宽度

| 通道类型 | 最小宽度 | 推荐宽度 | 说明 |
|----------|----------|----------|------|
| 主通道 | 900mm | 1000mm+ | 主要行走动线 |
| 次通道 | 600mm | 700mm+ | 家具间穿行 |
| 床侧通道（使用侧） | 500mm | 600mm+ | 远离窗户的一侧，日常上下床通行 |
| 床侧通道（窗侧） | 200mm | 300mm+ | 靠窗一侧，仅需预留窗帘安装空间；紧凑房型取最小值 200mm，剩余深度归使用侧 |
| 无障碍通道 | 1200mm | 1500mm | 轮椅通行 |

#### 通道分类判断规则

> **关键区分**：通道标准只适用于**需要人体通行的间隙**。判断依据是"人是否需要从此间隙穿过到达其他区域"，而非"两件家具之间是否存在间隙"。

| 间隙类型 | 判断方法 | 适用标准 |
|----------|----------|----------|
| 通行间隙 | 人需要从此处走过到达其他区域 | 主通道/次通道/床侧通道标准 |
| 使用间隙 | 人在旁边伸手操作即可，无需穿行 | 无最低通道要求 |

**常见使用间隙（非通道）**：
- 床头柜与相邻衣柜之间：人从床侧通道伸手操作床头柜，无需穿过此间隙
- 床头柜与墙面之间：无通行需求

**常见通行间隙（通道）**：
- 床使用侧边缘到对面衣柜：人需要从此处走过到达衣柜 → 按**床侧通道（使用侧）**标准（≥500mm），非主通道
- 床脚到墙面：人需要从此处走过进出房间 → 按**次通道**标准（≥600mm）

### 4.2 使用距离

| 场景 | 距离 | 说明 |
|------|------|------|
| 电视观看距离 | 屏幕对角线 × 2.5~3 | 55寸电视约3.5m |
| 餐椅后退空间 | 600~800mm | 起身活动空间 |
| 书桌椅后退空间 | 800~1000mm | 起身+通行 |
| 衣柜开门空间（平开门） | 600mm+ | 柜门向外打开，需要前方净空 |
| 衣柜开门空间（移门/滑门） | 0mm | 门扇沿柜面横向滑动，不占用前方空间 |
| 抽屉拉出空间 | 500mm+ | 床头柜、斗柜 |

#### 衣柜门扇类型选择指南

| 条件 | 推荐门扇类型 | 理由 |
|------|-------------|------|
| 柜体前方净空 ≥ 600mm | 平开门 | 取物方便、密封好、成本低 |
| 柜体前方净空 < 600mm | 移门/滑门 | 不占用前方空间，适合紧凑布局 |
| 柜体宽度 ≥ 2000mm | 移门/滑门 | 大柜体用移门操作更顺畅 |
| 极致收纳策略 | 移门/滑门优先 | 允许柜体贴近其他家具 |

> 注意：选择移门/滑门时，柜体深度不变（仍为600mm），但不需要预留前方开门空间。Agent 在 `placementReason` 中应注明选择的门扇类型及理由。

> **紧凑卧室联动提示**：当衣柜与床头柜相邻且前方净空受限时，应选择移门/滑门。移门无需前方开门空间，因此床头柜与衣柜之间的间隙不构成放弃床头柜的理由。

### 4.3 常用家具尺寸参考

| 家具 | 宽度(mm) | 深度(mm) | 备注 |
|------|----------|----------|------|
| 双人床 | 1800 | 2000 | 标准尺寸 |

## 五、房间布置要点

### 5.1 客厅 (LivingRoom)

- **功能标签**: `seating`, `media`, `storage`, `lighting`
- **锚点**: 电视柜位置决定沙发位置
- **核心关系**: 沙发正对电视，形成会客区
- **注意**: 保留主通道≥900mm，茶几与沙发距离400~500mm

### 5.2 主卧 (MasterBedroom)

- **功能标签**: `sleep`, `storage`, `dressing`, `lighting`
- **锚点**: 床头墙决定床位置
- **首选布局**: 「侧对窗户」——与次卧相同，床头靠侧墙（非窗墙、非门墙的实墙），床长边朝向窗户方向
- **核心关系**: 两侧放床头柜（主卧应成对）；先为两侧床头柜各预留 ≥ 其深度的空间（窗侧在窗帘之外），再将剩余空间偏向使用侧分配；仅紧凑房型窗侧取最小值 200mm
- **注意**: 床头不靠窗、床脚不正对门、衣柜应填满有效段全长（标准柜体阵列 + 定制柜体补充剩余宽度，补充件深度与主柜体一致）——连续柜面视觉更整洁，且最大化收纳效率
- **侧对窗户布局间距分配**：
  1. 窗侧：窗帘 200mm + 床头柜深度
  2. 使用侧：床头柜深度 + 剩余空间全部归此侧
  3. 紧凑判定：两侧都放下床头柜后使用侧 < 500mm 时，窗侧取最小值 200mm（仅窗帘），省略窗侧床头柜
- **衣柜墙面选择**：必须穷举房间边界上的每一段墙面（含 L 形拐角、延伸区墙段），逐段计算有效段长度后选最长者。L 形或异形主卧中，衣柜不必与床在同一子区域——入口附近的长墙面往往是更优选择（进门即取衣的动线优势，且不占用睡眠区通道宽度）

### 5.3 次卧 (Bedroom)

- **功能标签**: `sleep`, `storage`, `work`, `lighting`
- **锚点**: 床
- **首选布局**: 「侧对窗户」——床头靠侧墙（非窗墙、非门墙的实墙），床的长边朝向窗户方向，兼顾隐私与自然采光
- **特点**: 可能兼顾书房功能
- **衣柜布置**: 次卧有可用墙面时，应优先布置衣柜（储物是卧室核心功能之一）；仅当所有墙面都无法放置 600mm 深柜体（主通道 < 600mm）时，才允许省略衣柜
- **注意**: 空间较小时，床头柜可只放一个（优先保留远离窗户的一侧）
- **紧凑房型间距分配**（侧对窗户布局）：窗侧是功能性死区（仅窗帘安装），使用侧才是活动空间。窗侧取最小值 200mm，剩余空间全部分配给使用侧

### 5.4 餐厅 (DiningRoom)

- **功能标签**: `dining`, `storage`, `lighting`
- **锚点**: 餐桌位置
- **核心关系**: 餐椅环绕餐桌，餐边柜靠墙
- **注意**: 餐椅后留800mm起身空间

### 5.5 书房 (Study)

- **功能标签**: `work`, `storage`, `seating`, `lighting`
- **锚点**: 书桌位置
- **核心关系**: 书桌配椅子，书柜靠墙
- **注意**: 书桌最好侧对窗（左侧采光为佳）

## 六、朝向决策逻辑

### 6.1 床的朝向

| 优先级 | 规则 | 说明 |
|--------|------|------|
| 1 | 床头靠实墙 | 不靠窗墙、不靠门墙 |
| 2 | 侧对窗户 | 床头靠侧墙、长边朝窗，兼顾隐私与采光（主卧、次卧均适用） |
| 3 | 床头远离门 | 多面实墙可选时，优先选择离门最远的墙面（隐私+动线） |
| 4 | 床脚不正对门 | 传统习惯 |
| 5 | 床头朝向较长墙 | 空间利用最优 |

### 6.2 沙发的朝向

| 优先级 | 规则 | 说明 |
|--------|------|------|
| 1 | 背靠实墙 | 安全感 |
| 2 | 面向电视 | 功能需求 |
| 3 | 侧对窗户 | 采光舒适 |

### 6.3 书桌的朝向

| 优先级 | 规则 | 说明 |
|--------|------|------|
| 1 | 侧对窗户 | 左侧采光最佳 |
| 2 | 不背对门 | 心理安全感 |
| 3 | 面向墙壁 | 减少干扰 |

### 6.4 衣柜的墙面选择

卧室衣柜的墙面选择直接决定动线品质。

| 优先级 | 规则 | 说明 |
|--------|------|------|
| 1 | 穷举所有墙段 | 从房间边界提取每一条边，逐段评估，禁止跳过任何墙段（含 L 形拐角、延伸区） |
| 2 | 排除窗墙和床头墙 | 仅这两类排除；门墙仍为候选（需计算门后剩余段） |
| 3 | 计算有效段 | 无门窗墙面 = 整面墙长度；有门/窗墙面 = 扣除门窗开启区域后的最长连续剩余段 |
| 4 | 选有效段最长者 | 取有效段最长的候选墙面 |

> **有门的墙 ≠ 不可用的墙**：例如 5000mm 墙面有一扇 900mm 门，门后剩余段可能达 4000mm+，必须计算后再比较。
> **L 形房间**：衣柜不必与床在同一子区域——入口附近的长墙面往往是更优选择（进门即取衣的动线优势，且不占用睡眠区通道宽度）。

## 七、家具依赖关系

### 7.1 成套家具

| 依赖组 | 包含家具 | 说明 |
|--------|----------|------|
| `bedroom_core` | 床 + 床头柜(1~2) | 应成套放置；仅当某侧净空 < 500mm 时允许省略该侧 |
| `living_core` | 沙发 + 茶几 | 功能关联 |
| `dining_set` | 餐桌 + 餐椅(N) | 必须成套 |
| `work_set` | 书桌 + 椅子 | 必须成套 |

### 7.2 必须 vs 可选家具

| 房间 | 必须家具 | 可选家具 |
|------|----------|----------|
| 主卧 | 床、衣柜、床头柜(≥1) | 梳妆台、斗柜 |
| 次卧 | 床、衣柜、床头柜(≥1) | 书桌 |
| 客厅 | 沙发、电视柜 | 茶几、边几、落地灯 |
| 餐厅 | 餐桌、餐椅 | 餐边柜 |

> 次卧衣柜仅当所有墙面放置 600mm 深柜体后主通道 < 600mm 时允许省略。

### 7.3 功能互斥

- 一个卧室不放置两张床（除非是儿童房双床）
- 一个客厅不放置两组沙发
- 同一区域不重复放置同功能家具

## 八、策略参数化

| 策略 | 核心目标 | 通道宽度 | 家具选择 | 填充程度 |
|------|----------|----------|----------|----------|
| **极致收纳** | 最大化储物 | 可缩至600mm | 优先带储物功能 | 高 |
| **动线优先** | 宽敞动线 | ≥900mm | 减少大型家具 | 中 |
| **极简留白** | 只保留核心 | 充裕 | 仅必须家具 | 低 |
| **舒适优先** | 使用舒适度 | 适中 | 选大尺寸款 | 中 |
| **均衡方案** | 各方面均衡 | 标准 | 标准配置 | 中 |

### 策略对决策的影响

```python
if strategy == "StorageFirst":
    # 优先选择带储物的家具变体
    # 允许通道略窄（≥600mm）
    # 增加柜体数量

elif strategy == "CirculationFirst":
    # 保证通道≥900mm
    # 减少非必要家具
    # 选择较小尺寸款

elif strategy == "MinimalistFirst":
    # 只放置必须家具
    # 跳过所有可选家具
    # 大量留白
```

## 九、常见错误

### 9.1 布置陷阱

| 错误 | 说明 | 正确做法 |
|------|------|----------|
| 床脚正对门 | 传统忌讳 | 床侧对门或床头对门 |
| 沙发背对入口 | 心理不安 | 沙发背靠墙 |
| 通道过窄 | 无法通行 | 主通道≥900mm |
| 家具挡门 | 门无法完全打开 | 检查门扇弧线 |
| 床头靠窗 | 采光刺眼、噪音 | 床头靠实墙 |
| 书桌正对窗 | 眩光 | 侧对窗户 |
| 重复扣减完成面 | innerBoundary 已扣除完成面，再预留会浪费空间 | 直接以 innerBoundary 为边界 |
| 沿墙家具留出卫生死角 | 家具与墙角之间留出不足 600mm 的窄缝，无法使用又难清洁 | 家具贴靠实墙角，将空隙留在门口/通道一侧（参照顶角规则） |

### 9.2 自检清单

布置完成后，对照以下清单逐项检查。分为两级：硬性约束违反必须修正，设计规则优先修正。

**硬性约束（违反则必须修正，不能跳过）**：
- [ ] H1: 所有家具完全在 Zone 边界内（无越界）
- [ ] H2: 没有家具之间相互重叠
- [ ] H3: 没有家具与禁区（exclusion）重叠
- [ ] H4: 门可以完全打开（门前 900mm 净空无家具）
- [ ] H5: 主通道宽度 >= 900mm

**设计规则（优先修正，但不阻塞流程）**：
- [ ] S1: 锚点家具沿床头墙定位合理（参照 §5.2/§5.3 的布局间距分配规则）
- [ ] S2: 家具朝向符合 topology_rules / relation_rules
- [ ] S3: 衣柜沿最长连续有效段放置，且应填满有效段全长（标准柜体阵列 + 定制柜体补充）；有效段 = 扣除门窗开启区域后的连续可用墙面长度；有门的墙不等于不可用墙，需计算门两侧的剩余段长度
- [ ] S4: 床头靠实墙（非窗墙、非门墙）；次卧/主卧优先「侧对窗户」布局（床长边朝窗）；床脚不正对门
- [ ] S5: 成套家具已完整放置（床+床头柜、书桌+椅子）；有窗户的卧室/客厅应有窗帘
- [ ] S6: 家具间距合理（茶几离沙发 400-500mm、餐椅后退 600-800mm）
- [ ] S7: 沿墙家具（衣柜、书柜、鞋柜等）两侧无卫生死角（任一侧剩余 < 600mm 且非通道/门口时，应平移贴靠该侧墙角）
- [ ] S8: 卧室（含次卧）如有可用墙面，应布置衣柜；省略需说明原因（空间不足具体数据）
- [ ] S9: 同类型房间（如多个次卧）采用相同布局模式时，关键间距（窗侧、使用侧）应保持一致

# 第一部分：通用规则

> 以下规则适用于所有空间类型，布置任何房间前都应遵守。

---

## 一、设计原则

> **约束层级说明**：本文档规则标注约束强度，与 module_library.json 的标签体系对齐：
> - **【必须】**= 功能/安全约束，不可违反
> - **【建议】**= 设计规范，默认遵守，可在说明理由后偏离
> - **【提示】**= 设计偏好，鼓励 AI 根据场景灵活处理

| 规则 | 说明 | 适用家具 |
|------|------|----------|
| **【建议】靠墙规则** | 大型家具尽量靠墙放置——释放中央活动区域，减少空间碎片化 | 衣柜、床、沙发、书柜 |
| **【建议】居中规则** | 某些家具应居中于墙面——视觉均衡，避免偏重感 | 电视柜居中于电视墙、床居中于床头墙 |
| **【建议】顶角规则** | 大型家具无法填满整面墙时，优先贴靠实墙角，将剩余空隙留在门口/通道一侧——窄缝（< 600mm）积灰难清洁，形成卫生死角 | 衣柜、储物柜、书柜、鞋柜 |
| **【建议】朝向规则** | 家具背面靠墙，正面朝向空间中心——背墙提供心理安全感，正面朝空间便于使用 | 沙发背墙面向客厅、床头靠墙 |
| **【建议】对位规则** | 相关家具形成对位关系——功能对应最大化使用效率 | 沙发正对电视、餐椅围绕餐桌 |
| **【建议】避窗规则** | 避免家具阻挡采光——窗前大家具遮光且压缩空间感（淋浴区例外，详见 §11.5） | 床头不靠窗、书桌侧对窗 |
| **【必须】避门规则** | 不阻挡门的开启范围——门扇受阻导致功能丧失，门前还需方向转换缓冲区 | 所有家具 |
| **【建议】异形利用规则** | 异形空间（L形拐角、凹位、延伸区）的墙面利用——详见下方 §1.1 | 衣柜、梳妆台、斗柜、边几 |
| **【建议】前瞻协调规则** | 放置主要家具时，预判辅助家具的空间需求——窗帘需要窗墙全宽、梳妆台需要 600mm 站立空间等。若主要家具的位置会阻断辅助家具的必要空间（如衣柜占据窗墙角部导致窗帘无法满铺），应在放置时主动避让或预留 | 衣柜（预留窗帘角部）、沙发（预留茶几空间） |

### 1.1 异形利用规则详解

异形空间（L形拐角、凹位、延伸区）的墙面利用分三步：

1. **纳入衣柜评估**：异形区墙面必须纳入衣柜候选墙面评估（§7.4），不可跳过
2. **拆分剩余墙段**：衣柜仅占据墙面一部分时，计算该墙面的剩余连续空段。例如 1550mm 墙面衣柜占 600mm，剩余 950mm 是独立可用墙段
3. **【必须】异形区残余墙段优先**：步骤②识别的剩余墙段 + 未被选为衣柜墙的整面异形区墙面（统称"异形区残余墙段"），辅助家具**必须先在异形区残余墙段中搜索**，仅当异形区无满足条件的墙段时，才搜索主体区域墙面——异形区的独特尺寸恰好适配特定家具，化空间劣势为功能特色

#### 异形区 vs 主体区域的判断方法

对非矩形房间（L形、T形、凹字形等），用房间边界做分区：
- **主体区域**：房间内最大矩形子区域所覆盖的墙段
- **异形区**：主体区域以外的延伸/凹入部分的墙段

> **L 形房间示例**：主体矩形为较大的矩形块，则延伸出去的较小矩形块为异形区。异形区的每条边都是独立的异形区墙段。注意：L 形转折处连接主体与延伸区的那条较短竖边（或横边）属于**主体区域墙段**，不是异形区墙段。

## 二、布置优先级

```
1. 锚点家具 → 确定设计区的核心定位
2. 主要家具 → 围绕锚点布置
3. 辅助家具 → 填充剩余空间
```

| 房间 | 锚点家具 | 主要家具 | 辅助家具 |
|------|----------|----------|----------|
| 客厅 | 电视柜 | 沙发 | 茶几、边几、落地灯 |
| 主卧 | 床 | 衣柜、床头柜 | 窗帘、梳妆台、斗柜 |
| 次卧 | 床 | 衣柜、床头柜 | 窗帘、书桌 |
| 餐厅 | 餐桌 | 餐椅 | 餐边柜 |
| 书房 | 书桌 | 书柜 | 椅子、台灯 |
| 卫生间 | 淋浴屏/淋浴房 | 坐便器、台盆 | 花洒 |

> **次卧衣柜说明**：衣柜是卧室储物核心，次卧中应与床同步规划（阶段 A 主要家具）。省略条件见 §7.2。

## 三、空间约束

Agent 布置时必须满足以下硬性约束：

```
1. bounds 必须完全在 Zone.innerBoundary 内
2. bounds 不能与任何 exclusionAreas 重叠
3. bounds 不能与其他已放置 modules 重叠
4. 不能阻挡门的开启范围（门扇弧线区域）
```

> **重要：无需考虑墙面完成面**
> `Zone.innerBoundary` 已经是扣除完成面厚度后的净空边界。AI 布置家具时直接以 `innerBoundary` 为可用范围即可，**不需要**再额外预留完成面空间。重复扣减会导致可用空间被不必要地缩小。

## 四、尺寸标准

### 4.1 通道宽度

| 通道类型 | 最小宽度 | 推荐宽度 | 说明 |
|----------|----------|----------|------|
| 主通道 | 900mm | 1000mm+ | 主要行走动线——人体正面行走最小宽度 |
| 次通道 | 600mm | 700mm+ | 家具间穿行——人体侧转通行宽度 |
| 床侧通道（使用侧） | 500mm | 600mm+ | 日常上下床——低于 500mm 上下床困难（远离窗户的一侧） |
| 床侧通道（窗侧） | 200mm | 300mm+ | 此侧不需人体通行，仅预留窗帘空间；紧凑房型取最小值 200mm，剩余深度归使用侧 |
| 无障碍通道 | 1200mm | 1500mm | 轮椅通行 |

#### 通道分类判断规则

> **关键区分**：通道标准只适用于**需要人体通行的间隙**。判断依据是"人是否需要从此间隙穿过到达其他区域"，而非"两件家具之间是否存在间隙"。

| 间隙类型 | 判断方法 | 适用标准 |
|----------|----------|----------|
| 通行间隙 | 人需要从此处走过到达其他区域 | 主通道/次通道/床侧通道标准 |
| 使用间隙 | 人在旁边伸手操作即可，无需穿行 | 无最低通道要求 |

**常见使用间隙（非通道）**：
- 床头柜与相邻衣柜之间：人从床侧通道伸手操作床头柜，无需穿过此间隙
- 床头柜与墙面之间：无通行需求

**常见通行间隙（通道）**：
- 床使用侧边缘到对面衣柜：人需要从此处走过到达衣柜 → 按**床侧通道（使用侧）**标准（≥500mm），非主通道
- 床脚到墙面：人需要从此处走过进出房间 → 按**次通道**标准（≥600mm）

### 4.2 使用距离

| 场景 | 距离 | 说明 |
|------|------|------|
| 电视观看距离 | 屏幕对角线 × 2.5~3 | 55寸电视约3.5m |
| 餐椅后退空间 | 600~800mm | 起身活动空间 |
| 书桌椅后退空间 | 800~1000mm | 起身+通行 |
| 衣柜开门空间（平开门） | 600mm+ | 柜门向外打开，需要前方净空 |
| 衣柜开门空间（移门/滑门） | 0mm | 门扇沿柜面横向滑动，不占用前方空间 |
| 抽屉拉出空间 | 500mm+ | 床头柜、斗柜 |

## 七、封闭空间：卧室

### 7.1 主卧布置要点

- **功能标签**: `sleep`, `storage`, `dressing`, `lighting`
- **锚点**: 床头墙决定床位置
- **首选布局**: 「侧对窗户」——床头靠侧墙（非窗墙、远离门段的实墙），床长边朝向窗户方向（详见 §7.6）。门段定义见 §7.3
- **核心关系**: 两侧放床头柜（主卧应成对）；间距分配见 §7.6
- **注意**: 床头不靠窗、床脚不正对门、衣柜应填满有效段全长（标准柜体阵列 + 定制柜体补充剩余宽度，补充件深度与主柜体一致）——连续柜面视觉更整洁，且最大化收纳效率

### 7.2 次卧布置要点

- **功能标签**: `sleep`, `storage`, `work`, `lighting`
- **锚点**: 床
- **首选布局**: 「侧对窗户」——同主卧（详见 §7.6）
- **特点**: 可能兼顾书房功能
- **衣柜布置**: 次卧有可用墙面时，应优先布置衣柜（储物是卧室核心功能之一）；仅当所有墙面都无法放置 600mm 深柜体（主通道 < 600mm）时，才允许省略衣柜
- **注意**: 空间较小时，床头柜可只放一个（优先保留远离窗户的一侧）

### 7.3 床的朝向决策

| 优先级 | 规则 | 说明 |
|--------|------|------|
| 1 | **【必须】**床头靠实墙 | 窗墙：光线+噪音干扰睡眠、心理不安全；门段（门洞 + 两侧各 500mm 缓冲）：入口噪音+隐私暴露。注意：排除的是"门段"而非"整面门墙"——同一面墙上远离门的实墙段仍可作为床头候选 |
| 2 | **【建议】**侧对窗户 | 晨光从侧面温和照入（自然唤醒）、窗外视线不直视床头（隐私）（主卧、次卧均适用） |
| 3 | **【建议】**床头远离门 | 睡眠区与入口动线分隔，减少进出活动对睡眠的干扰 |
| 4 | **【建议】**床脚不正对门 | 入门视线直扑床脚产生视觉压迫感，削弱卧室私密氛围 |
| 5 | **【提示】**床头朝向较长墙 | 短墙方向放床可能两侧余量不足以放床头柜 |

### 7.4 衣柜布局模式与墙面选择

卧室衣柜的布局直接决定空间感受、动线品质和功能分区。衣柜有两种基本布局模式：

#### 模式判断

| 模式 | 形态 | 适用场景 |
|------|------|----------|
| **L 形转角** | 衣柜沿两面相邻墙形成 L 形 | 房间存在可用墙角（两面相邻候选墙），主臂有效段 ≥ 1200mm，副臂有效段 ≥ 600mm |
| **线性** | 衣柜沿单面墙线性排列 | 无合适的 L 形转角机会，或房间过小 |

**【建议】优先评估 L 形转角模式**，仅当条件不满足时回退到线性模式。

#### L 形转角衣柜

**设计理念**：L 形转角不只是"换一面墙放衣柜"，而是一种空间组织策略——

- **功能分区**：L 形天然将房间分割为不同功能区（如"换衣区"与"睡眠区"、"通卫区"与"睡眠区"），主臂起到类似屏风的作用，增强空间层次感
- **动线优化**：衣柜集中在墙角区域，避免占据房间中部墙面，保持主动线通畅
- **储纳增量**：两面墙的组合有效段通常大于单面墙，同时不压缩任何一面墙的通道宽度
- **空间释放**：床的正前方保持开阔，主活动区域不被 600mm 衣柜深度压缩

**适用条件**（同时满足）：
1. 房间有至少两面相邻的候选墙（非窗墙），形成一个可用墙角——穷举所有墙角，不限于入口附近（L 形的功能分区价值不依赖于是否靠近入口；远离入口的墙角同样能实现储纳增量和空间释放）
2. **主臂**有效段 ≥ 1200mm；**副臂**有效段 ≥ 600mm——副臂的价值在于"转角延伸"而非"独立储物墙"，即使较短也能形成 L 形空间组织效果
3. 副臂末端到对面墙/家具 ≥ 900mm（主通道不被阻挡）

**布置方式**：
1. **选角**：穷举所有候选墙角，选择满足适用条件且综合价值最高的墙角（评估要素：主臂有效段长度、副臂有效段长度、是否压缩床前通道、是否利于功能分区）
2. **主臂**：沿有效段较长的那面墙布满衣柜（贴靠转角，空隙留在远离转角的一端）。若与床头共用墙面（见 step 5），主臂仅占据远离床头的区段
3. **副臂**：从转角沿相邻墙延伸，长度 = 该墙有效段长度（有门窗时取扣除后的连续段）——副臂越长分区效果越强，但不应侵占床头柜或通道空间
4. **转角处理**：两段柜体在转角处 90° 相接，无需特殊转角模块
5. **床头墙共用**：L 形某一臂可与床头共用同一面物理墙——衣柜臂占据远离窗户的区段，床占据靠窗的区段，两者之间通常由床头柜自然分隔

> **与线性模式的关键区别**：线性模式"排除床头墙"是因为整面墙放衣柜会直接堵在床头后方。L 形转角中某一臂仅占用床头墙的部分区段（远离床头的一端），不构成同样的问题。

#### 线性布局（回退方案）

当 L 形转角条件不满足时，按以下步骤选择单面墙：

| 步骤 | 规则 | 说明 |
|------|------|------|
| 1 | **【必须】**穷举所有墙段 | 从房间边界提取每一条边，逐段评估，禁止跳过任何墙段（含 L 形拐角、延伸区） |
| 2 | **【必须】**排除窗墙和床头墙 | 仅这两类排除；门墙仍为候选（需计算门后剩余段） |
| 3 | **【必须】**计算有效段 | 无门窗墙面 = 整面墙长度；有门/窗墙面 = 扣除门窗开启区域后的最长连续剩余段 |
| 4 | **【建议】**选有效段最长者 | 取有效段最长的候选墙面 |
| 5 | **【必须】**床前通道检查 | 若选定墙面是床正对面墙，计算：房间进深 - 床深度 - 衣柜深度(600mm)。当结果 < 800mm 时，**必须**换到其他候选墙面——床前通道是房间内主要行走动线，低于 800mm 日常通行受阻 |

> **有门的墙 ≠ 不可用的墙**：例如 5000mm 墙面有一扇 900mm 门，门后剩余段可能达 4000mm+，必须计算后再比较。

**线性布局计算示例**：次卧 3600×3000mm，北墙有窗、南墙有门（900mm 宽，居左）
1. 北墙（3600mm）：窗墙 → 排除
2. 南墙（3600mm）：门占 900mm + 门前净空 900mm = 1800mm，剩余有效段 = 3600 - 1800 = 1800mm
3. 东墙（3000mm）：床头墙 → 排除
4. 西墙（3000mm）：无门窗，有效段 = 3000mm → **选中**（最长）

### 7.5 衣柜门扇类型

| 条件 | 推荐门扇类型 | 理由 |
|------|-------------|------|
| 柜体前方净空 ≥ 600mm | 平开门 | 取物方便、密封好、成本低 |
| 柜体前方净空 < 600mm | 移门/滑门 | 不占用前方空间，适合紧凑布局 |
| 柜体宽度 ≥ 2000mm | 移门/滑门 | 大柜体用移门操作更顺畅 |
| 极致收纳策略 | 移门/滑门优先 | 允许柜体贴近其他家具 |

> 注意：选择移门/滑门时，柜体深度不变（仍为600mm），但不需要预留前方开门空间。Agent 在 `placementReason` 中应注明选择的门扇类型及理由。

> **紧凑卧室联动提示**：当衣柜与床头柜相邻且前方净空受限时，应选择移门/滑门。移门无需前方开门空间，因此床头柜与衣柜之间的间隙不构成放弃床头柜的理由。

### 7.6 侧对窗户布局间距分配

> 本节适用于主卧和次卧，统一定义「侧对窗户」布局的间距分配逻辑。

**布局原则**：先为两侧床头柜各预留 ≥ 其深度的空间（窗侧在窗帘之外），再将剩余空间偏向使用侧分配。

**间距分配步骤**：
1. **窗侧**：窗帘 200mm + 床头柜深度
2. **使用侧**：床头柜深度 + 剩余空间全部归此侧
3. **紧凑判定**：两侧都放下床头柜后使用侧 < 500mm 时，窗侧取最小值 200mm（仅窗帘），省略窗侧床头柜

**主卧 vs 次卧差异**：
| 维度 | 主卧 | 次卧 |
|------|------|------|
| 床头柜数量 | 应成对（2个） | ≥ 1 个即可 |
| 紧凑时省略 | 省略窗侧床头柜 | 省略窗侧床头柜 |
| 仅窗帘时窗侧间距 | 200mm | 200mm |

> 省略任何成套家具必须给出原因（如"使用侧 < 500mm，省略窗侧床头柜"）。

## 十一、卫生间

### 11.1 基础规则

- **功能标签**: `shower`, `toilet`, `washing`
- **锚点**: 淋浴屏/淋浴房（确定干湿分区位置）
- **【建议】洁具排布顺序**（从入口到深处）: 台盆（进出洗手方便） → 坐便器（隐私） → 淋浴区（最深处，干湿分离）
- **【建议】台盆贴角规则**: 台盆应贴靠相邻墙角放置，不留无功能间隙——窄缝积灰难清洁（同理于 §1「顶角规则」）
- **【建议】坐便器居中规则**: 坐便器应在其可用墙段（台盆边沿 ↔ 淋浴屏边沿）内居中布置——两侧预留对称操作空间
- **【建议】台盆选型**: 当台盆可用墙面长度 > 标准台盆宽度（850mm）时，应选用定制台盆（horizontal_fill），最大化台面空间
- **【必须】窄卫生间规则**: 当卫生间宽度 ≤ 1800mm 时，坐便器与台盆应集中布置于同一侧墙面，对侧保留完整通道——分列两侧时中间通道被压缩到无法通行
- **【建议】花洒墙面选择**: 花洒应安装在淋浴区内的实墙（非窗墙）上——走管安装需要实墙支撑

### 11.2 布局模式总览

根据卫生间房型特征，有 5 种典型布局模式。Agent 不需要"像设计师一样创造性规划"，而是"查决策树选模板 + 参数化微调"。

| 模式 | 适用房型 | 核心特征 | 洁具配置 |
|------|---------|---------|---------|
| **A: 单侧线性** | 窄长型，短边 ≤ 1800mm | 全部沿一侧墙排列，对侧留通道 | 台盆 → 坐便器 → 淋浴屏（一字型） |
| **B: L 形** | 窄长型，短边 > 1800mm，长宽比 > 1.5 | 淋浴间横占远端，其余沿侧墙 | 台盆 + 坐便器侧墙，淋浴屏/淋浴房尽端 |
| **C: 分墙** | 近方形，面积 ≤ 6㎡ | 洁具分布在相邻两面墙 | 淋浴房占远离门角落 |
| **D: 三面分布** | 面积 > 6㎡ | 三面墙各一类洁具，中央通道宽裕 | 空间宽裕，可用大尺寸 |
| **E: 半卫** | 小面积，无淋浴需求 | 仅台盆 + 坐便器并列 | 最简配置 |

### 11.3 模式选择决策树

按以下顺序逐步判断（命中即停）：

**1. 是否有淋浴需求？**
- 检查 zone.tags 是否包含 `shower`
- 无 → **模式 E（半卫）**
- 有 → 继续

**2. 短边宽度 ≤ 1800mm？**
- 从 zone.rawBoundary 计算最小外接矩形，取短边
- 是 → **模式 A（单侧线性）**
- 否 → 继续

**3. 长宽比 > 1.5？**
- 长边 / 短边
- 是 → **模式 B（L 形）**
- 否 → 继续

**4. 面积 > 6㎡？**
- 否 → **模式 C（分墙）**
- 是 → **模式 D（三面分布）**

**门位置修正规则**（影响排列起点方向，不影响模式选择）：
- 门在短边：台盆排布从门侧开始（进门即洗手）
- 门在长边：台盆靠门所在长边的近端

> 以上阈值基于初期案例，后续可根据实际项目调整。

### 11.4 各模式详细定位规则

#### 模式 A：单侧线性（短边 ≤ 1800mm）

**空间特征**：窄长型卫生间，宽度不足以两侧布置洁具。

**排列规则**：
1. 全部洁具沿一侧长墙排列——墙面选择：门在长边 → 选对面长墙；门在短边 → 选距门洞中心较远的长墙（入门后视线不正对洁具侧面）
2. 排列顺序（从门端到深处）：台盆 → 坐便器 → 淋浴区
3. 对侧墙面保留完整通道（≥ 700mm）

**洁具定位**（台盆贴角、坐便器居中、台盆选型、花洒墙面等通用规则参照 §11.1）：
- **台盆**：贴靠门端墙角
- **坐便器**：紧接台盆，在「台盆边沿 ↔ 淋浴屏边沿」可用段内居中
- **淋浴屏**：`mod_shower_linear`（horizontal_fill，宽度 = 短边宽度），连接两面实墙

#### 模式 B：L 形（短边 > 1800mm，长宽比 > 1.5）

**空间特征**：略宽的长方形，允许淋浴间横向占据远端。

**排列规则**：
1. 淋浴间横占远端（深处短边方向），形成独立湿区
2. 台盆 + 坐便器沿同一侧长墙排列

**洁具定位**（通用规则参照 §11.1）：
- **淋浴**：`mod_shower_corner` 或 `mod_shower_linear`，占据远端墙面
- **台盆**：贴靠门端墙角
- **坐便器**：在台盆与淋浴间之间

#### 模式 C：分墙（近方形，面积 ≤ 6㎡）

**空间特征**：近正方形空间，宽度足够但总面积不大。

**排列规则**：
1. 洁具分布于相邻两面墙
2. 台盆靠门侧墙面
3. 坐便器 + 淋浴间靠对面/相邻墙面
4. 淋浴间占据远离门的角落

**洁具定位**（通用规则参照 §11.1）：
- **淋浴房**：`mod_shower_corner`，放在远离门的角落
- **台盆**：靠门侧墙面贴角
- **坐便器**：与淋浴房同侧或相邻墙面

#### 模式 D：三面分布（面积 > 6㎡）

**空间特征**：宽裕的卫生间，可奢侈分配。

**排列规则**：
1. 三面墙各分配一类洁具
2. 门对面墙放淋浴间
3. 门两侧墙面分别放台盆和坐便器
4. 中央保留宽裕通道

**洁具定位**（通用规则参照 §11.1）：
- **淋浴房**：`mod_shower_corner`，尺寸可按空间放大
- **台盆**：优先选定制台盆，最大化台面
- **坐便器**：单独占一面墙段

#### 模式 E：半卫（无淋浴）

**空间特征**：小面积卫生间，仅需台盆 + 坐便器。

**排列规则**：
1. 台盆靠门侧
2. 坐便器在台盆之后

**洁具定位**（通用规则参照 §11.1）：
- **台盆**：贴靠门端墙角
- **坐便器**：紧接台盆
- 无淋浴相关模块

#### 模块选型速查表

| 洁具 | 默认模块 | 条件触发替换 |
|------|---------|-------------|
| 台盆 | `mod_basin_001`（fixed，850×550mm） | 可用墙面 > 850mm → `mod_basin_custom_001`（horizontal_fill，850~2000mm） |
| 坐便器 | `mod_toilet_001`（fixed，400×650mm） | 无替换 |
| 淋浴隔断 | `mod_shower_linear`（horizontal_fill，800~2000mm） | 模式 C/D 且角落空间充裕 → `mod_shower_corner`（parametric，各 800~1200mm） |
| 花洒 | `mod_shower_head`（fixed，135×165mm） | 无替换；安装在淋浴区内实墙 |

### 11.5 避窗规则特例

卫生间的避窗规则与封闭空间（卧室/书房）**相反**：

| 空间类型 | 窗户规则 | 原因 |
|---------|---------|------|
| 封闭空间（卧室） | 床头**避窗** | 采光刺眼、噪音、隐私 |
| 卫生间 | 淋浴区**可临窗** | 采光通风好 |

具体规则：
- 淋浴区域本身可布置在窗户旁（不受 §1 避窗规则限制）
- 花洒墙面选择参照 §11.1（花洒应安装在实墙上）
- 坐便器避免正对窗户（隐私）

## 十二、常见错误

### 12.1 布置陷阱

| 错误 | 说明 | 正确做法 |
|------|------|----------|
| 床脚正对门 | 传统忌讳 | 床侧对门或床头对门 |
| 沙发背对入口 | 心理不安 | 沙发背靠墙 |
| 通道过窄 | 无法通行 | 主通道≥900mm |
| 家具挡门 | 门无法完全打开 | 检查门扇弧线 |
| 床头靠窗 | 采光刺眼、噪音 | 床头靠实墙 |
| 书桌正对窗 | 眩光 | 侧对窗户 |
| 重复扣减完成面 | innerBoundary 已扣除完成面，再预留会浪费空间 | 直接以 innerBoundary 为边界 |
| 沿墙家具留出卫生死角 | 家具与墙角之间留出不足 600mm 的窄缝，无法使用又难清洁 | 家具贴靠实墙角，将空隙留在门口/通道一侧（参照顶角规则） |

# 卧室策略

适用：tags 含 `sleep` 或 `bedroom` 的封闭空间。本 Skill 指导**策略生成**——从空间画像推导出布局方案，不含流程步骤（流程由 generate-workflow 管理）。

---

## 空间理解补充

在 generate-workflow 产出的通用空间画像基础上，补充卧室特有分析：

从 `get_zone_boundaries` 返回的墙面清单构建候选（数据驱动，不需手动推断）：

1. **床头墙候选**：排除窗墙整面、排除门段区域（门洞+两侧各500mm），附候选墙实墙长度
2. **衣柜墙候选**：所有非窗墙面，有效长度 = 实墙总长 - exclusion zone 扣减
3. **窗户朝向**：窗墙位置 → 决定"侧对窗户"的床头墙方向
4. **通道识别**（子分区场景）：passage 段 = 与相邻分区的开放连通，**禁止靠通道放大型家具**

> WHY：`get_zone_boundaries` 已按墙面分组并标注实墙长度——直接筛选候选，不从 rawBoundary 推断。passage 在子分区场景中区分实墙和通道，靠通道放衣柜会阻断分区间通行。

## 策略生成

### 锚点决策：床头墙选择

按优先级逐级筛选（高优先级不满足时降级）：

| 优先级 | 规则 | WHY |
|--------|------|-----|
| 1 | **【必须】**床头靠实墙（排除窗墙、门段） | 窗墙光线噪音干扰睡眠；门段入口噪音+隐私暴露 |
| 2 | **【建议】**侧对窗户（床长边朝窗方向） | 晨光从侧面温和照入，自然唤醒；窗外视线不直视床头 |
| 3 | **【建议】**床头远离门 | 睡眠区与入口动线分隔，减少干扰 |
| 4 | **【建议】**床脚不正对门 | 入门视线直扑床脚产生压迫感 |
| 5 | **【提示】**较长墙优先 | 两侧余量放床头柜；短墙可能放不下成套床组 |

> 注意：排除的是"门段"而非"整面门墙"——同一面墙上远离门的实墙段仍可作候选。

### 衣柜决策：选墙 → 选模式

**分区场景前置**：当本 zone 来自分区（边界含 passage 段），衣柜的墙面选择已在分区阶段做过全局审视。如果分区阶段将 wardrobeStorage 标签分配给了本 zone，遵循该决策；如果衣柜被分配到其他子 zone，本 zone 不再重复评估衣柜。

**模式判断**：**【建议】**优先评估 L 形，条件不满足时回退线性。

**L 形衣柜**（两种布局方式）：

| 布局方式 | 特征 | 空间效果 |
|---------|------|---------|
| **传统布局** | 沿墙段+垂直段（短边靠墙，长边伸入房间） | 垂直段形成隔断，创造半封闭换衣区 |
| **L型靠墙** | 所有段长边贴墙，沿墙角展开 | 最大化墙面利用率，适合紧凑空间 |

> WHY：传统布局通过垂直段创造"换衣区"——功能分区和使用体验更好。L型靠墙则最大化墙面利用率。不是好坏之分，而是空间组织策略的选择。

**布局方式选择**：默认传统布局。仅当垂直段阻挡通卫动线（末端到对面 < 900mm）时降级为 L型靠墙。垂直段方向远离卫生间门。

**线性布局**（回退方案）：
1. **【必须】**穷举 boundarySegments 中所有墙面，逐面评估
2. 排除窗墙整面 + 床组占据段
3. 计算有效段（按 exclusion zone 扣减）
4. 选有效段最长者
5. **【必须】**床前通道检查：若选定墙是床对面，房间进深-床深-柜深 < 800mm → 换墙

**【建议】**衣柜应填满有效段全长（标准柜体+定制补充）——连续柜面视觉整洁，最大化收纳。

### 家具配置

| 家具 | 主卧 | 次卧 |
|------|------|------|
| 床 | 必须 | 必须 |
| 衣柜 | 必须 | 有可用墙面时必须（所有墙面净空<600mm才可省略）|
| 床头柜 | 成对（2个） | ≥1个（优先保留远离窗户的一侧）|
| 窗帘 | 有窗则必须 | 有窗则必须 |

### 辅助家具（自由区域）

梳妆台、斗柜、展示柜、落地灯等——位置由你自主决定。

**评估方法**：锚点+主要家具确定后，扫描所有剩余墙段，逐段评估最适合的辅助家具。优先级：异形区残余墙段 → 主体区未占用墙段。"次之"是优先级低，不是"不放"——只要通道允许（次通道≥600mm），空墙段应当被利用。

**功能组合优先**：放置第二件及以上辅助家具时，先评估与已放置家具的功能组合潜力——同功能区内的辅助家具应优先形成空间组合（L 形/并排），再为组合整体选位，而非逐件独立匹配墙段。

WHY：化妆台+收纳柜形成 L 形组合 = 完整梳妆工作站（伸手即取）；散落两面墙 = 两件孤立家具。组合带来的功能协同 > 单件家具的"最优墙段"。辅助家具让空间从"能用"升级到"好用"。一面空着的1.8m实墙是浪费的设计资源。

## 策略声明示例

> 以下示例展示从空间画像到策略的完整推导。参照此密度和推理风格。

**场景**：3.6m × 4.2m 主卧，南墙窗户，北墙入口偏左

**空间画像摘要**：
```
动线：北墙偏左入口 → 南向到窗
纵深：北(入口/前场) → 南(窗/深处)
采光：南墙窗户，采光轴南北

get_zone_boundaries 返回：
  北墙 | 总长 4000mm | 实墙 3200mm
    wall 1200mm ... + door(d_1) 800mm ... + wall 2000mm ...
  东墙 | 总长 3600mm | 完整实墙
  南墙 | 总长 3600mm | 实墙 800mm（窗墙）
    wall 400mm ... + window(wi_1) 2800mm ... + wall 400mm ...
  西墙 | 总长 3600mm | 完整实墙

床头墙候选（排除窗墙 + 门段缓冲）：
  东墙 3.6m 完整实墙（最长）| 西墙 3.6m 完整实墙 | 北墙右侧约 2.0m（扣门段500mm缓冲）

衣柜墙候选：
  北墙右侧 2.0m | 东墙 3.6m（若不给床）| 西墙 3.6m（若不给床）
```

**策略推导**：
- **床头墙** → 东墙：最长实墙 ✓ 侧对南窗 ✓ 远离北墙门 ✓ 不正对门 ✓
- **衣柜** → 北墙右侧 2.4m + 西墙北端形成 L 形：传统布局，垂直段从西墙北端向南伸出（远离北墙门，不阻通卫），创造入口侧半封闭换衣区
- **间距** → 窗侧=窗帘200mm+床头柜深度，使用侧=床头柜深度+剩余全部
- **配置** → 床(1800×2000) + L形衣柜 + 床头柜×2 + 窗帘 + [辅助]梳妆台（西墙南段，靠窗采光好）

## 关键约束速查

**硬约束**：
- 床头禁靠窗墙 — 光线噪音+心理不安全
- 穷举所有墙段评估衣柜 — 禁止跳过任何候选（含异形区墙段）
- L型靠墙内角门开启检查 — 按方案A(移门)→B(足够外露)顺序评估

**软指导**：
- 衣柜填满有效段全长 — 连续柜面+最大化收纳
- 侧对窗户 — 晨光温和+隐私
- 成对床头柜（主卧）— 视觉对称+双人便利
- 大型家具贴靠实墙角 — 窄缝积灰难清洁

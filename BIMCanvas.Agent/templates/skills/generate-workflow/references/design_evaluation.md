# 设计评价标准

> 品质标准不是事后审查清单——它是贯穿策略→执行→审查的设计目标。
> 策略阶段声明品质目标 → 执行阶段围绕目标决策 → 审查阶段验证目标达成。

---

## 策略阶段：如何声明设计目标

### 步骤 1：选取 1-3 个最相关的维度

根据空间特征优先选取：

| 空间特征 | 优先选取的维度 |
|---------|--------------|
| 入口位置偏向一端（非居中） | 动线设计（开阔侧原则） |
| 明显的入口→深处轴向 | 空间节奏（隐私梯度） |
| 异形区/L形延伸（≥3m²） | 空间意图（异形区功能化） |
| 多件家具集中同一墙面 | 功能叙事（墙面主题统一） |
| 自然采光明显（大窗/朝南） | 采光通风（功能-光匹配） |

无显著特征时，各房间类型的默认维度组合：

| 房间类型 | 默认维度 |
|---------|---------|
| 卫生间 | 动线设计 + 空间节奏 |
| 卧室 | 空间节奏 + 功能叙事 |
| 客餐厅 | 功能叙事 + 空间节奏 + 采光通风 |

### 步骤 2：写入策略声明

格式：
```
**设计目标**：[维度1的目标描述(维度名)] / [维度2的目标描述(维度名)] / [维度3（如有）]
```

示例（卫生间）：
`**设计目标**：进门右转直达台盆(动线) / 东墙统一洗漱+如厕功能(功能叙事) / 洗手→如厕→淋浴由浅入深(空间节奏)`

示例（主卧）：
`**设计目标**：L形衣柜构成连续存储叙事墙(功能叙事) / 入口→更衣区→床的隐私递进(空间节奏) / 梳妆台靠南窗采光(采光通风)`

示例（客厅）：
`**设计目标**：电视柜+沙发+茶几形成完整休闲叙事(功能叙事) / 餐厅→客厅→窗景的渐进体验(空间节奏) / 南窗采光最大化给主活动区(采光通风)`

### 步骤 3：设计目标是执行阶段每个决策的判据

放置每件家具时追问：**"这个位置是否有助于实现我声明的设计目标？"**
- 选墙时想动线 → 门偏向哪侧？开阔侧在哪？
- 分组时想叙事 → 这件家具与哪件配对？能构成连贯功能组吗？
- 留白时想节奏 → 这个空白是有意识的缓冲还是无意识的残留？
- 靠窗时想采光 → 需要自然光的功能放到了采光好的位置吗？

> WHY：有了"进门直达台盆"这个目标，选墙时就不需要纠结公式——目标本身已经指明了方向。没有声明的目标，执行阶段只能靠规则逐条检查，遇到规则未覆盖的场景就看运气。

## Layer 1：工程合规（底线）

通过 = 布局物理可行且功能完整。不通过时不进入 Layer 2。

| 检查项 | 含义 | 方式 |
|--------|------|------|
| 几何合法 | 不越界/穿墙/占柱/侵禁区/重叠 | validate_layout 自动 |
| 通行可达 | 入口→每件家具使用面+每扇窗 | 坐标算术，主≥900mm 次≥600mm |
| 功能完整 | zone.tags 每个标签有对应模块 | 比对 tags 与已放置模块 |

> 示例：tags=[sleep, wardrobeStorage] 但无衣柜 → 功能丢失 → Layer 1 不通过。

---

## Layer 2：设计品质（审查参照）

审查时，逐条核对策略阶段声明的设计目标是否达成——不是对照通用清单，而是验证自己承诺的目标。

### 动线设计
> 核心问题：从入口到每个功能点的路径直觉吗？功能沿动线递进吗？

**审查参照**（策略声明了动线目标时核对）：
- ✓ 卫生间门偏西，洁具放东墙——进门自然右转直达台盆
- ✗ 卫生间门偏西，洁具放西墙——进门后要折返
- ✓ 卧室：衣柜在入口侧，床在深处——更衣在前，休息在后
- ✗ 卧室：床紧挨门口，入门即见床——无过渡缓冲

### 空间意图
> 核心问题：每个区域有可命名的功能身份吗？有无意识的剩余空间吗？

**审查参照**（策略声明了空间意图目标时核对）：
- ✓ L形延伸做更衣区——异形空间被赋予明确功能
- ✗ L形延伸空置——"家具放完剩下的"
- ✓ 有意识的留白：入口缓冲区（过渡需要）、主通道（动线需要）
- ✗ 无意识的残留：<600mm 窄缝，既不是通道也不是收纳

### 功能叙事
> 核心问题：同一区域的家具讲述连贯的功能故事吗？

**审查参照**（策略声明了功能叙事目标时核对）：
- ✓ 台盆+镜柜+毛巾架组成洗漱区——功能群组连贯
- ✗ 衣柜-空隙-床头柜-书桌混杂同一面墙——碎片化
- ✓ 连续衣柜墙——换衣视线所及全是收纳，功能无断点
- ✗ 衣柜被梳妆台插断——存储叙事断裂

### 空间节奏
> 核心问题：入口到深处有隐私/密度的递进吗？留白是有意识的吗？

**审查参照**（策略声明了空间节奏目标时核对）：
- ✓ 卫生间：台盆(公开)→马桶(半私密)→淋浴(最私密)——隐私梯度
- ✗ 马桶紧挨门口——进门一览无余
- ✓ 卧室：更衣区在入口侧，床在深处——公共→私密递进
- ✓ 客餐厅：餐厅(入口/过渡)→客厅(深处/休闲)——密度渐进

### 采光通风
> 核心问题：窗户资源被合理利用了吗？光路通畅吗？

**审查参照**（策略声明了采光通风目标时核对）：
- ✓ 梳妆台靠窗——化妆需要自然光
- ✗ 高衣柜正对窗——深处空间变暗
- ✓ 书桌/梳妆台靠采光侧——功能与光匹配
- ✓ 客厅主活动区朝南窗——最优采光给使用频率最高的区域

     │                                                                         │
     │ 6.1 核心功能                                                            │
     │                                                                         │
     │ - SVG 渲染与缩放平移                                                    │
     │ - 元素选择与拖拽                                                        │
     │ - 实时同步（AI操作 ↔ 用户操作）                                         │
     │ - 批注绘制工具                                                          │
     │ - 撤销/重做                                                             │
     │                                                                         │
     │ 6.2 技术选型建议                                                        │
     │                                                                         │
     │ - 前端框架: Vue 3 或 React                                              │
     │ - SVG 操作: SVG.js 或 Fabric.js                                         │
     │ - 实时通信: WebSocket (SignalR)                                         │
     │ - 状态管理: Pinia 或 Zustand                                            │
     │                                                                         │
     │ 6.3 Web 的优势                                                          │
     │                                                                         │
     │ - 跨平台，无需安装                                                      │
     │ - 易于与 Claude Code 集成（通过 URL 打开）                              │
     │ - SVG 原生支持好                                                        │
     │ - 丰富的交互库可选                                                      │

     │ 7. 实时同步架构                                                         │
     │                                                                         │
     │ 7.1 架构图                                                              │
     │                                                                         │
     │ ┌───────────────┐         ┌─────────────────────┐                       │
     │ ┌───────────────┐                                                       │
     │ │  Claude Code  │         │  BIMCanvas.Web      │         │    用户     │
     │   │                                                                     │
     │ │  (AI Agent)   │         │  .Server            │         │  Web Browser│
     │   │                                                                     │
     │ └───────┬───────┘         └──────────┬──────────┘                       │
     │ └───────┬───────┘                                                       │
     │         │                            │                            │     │
     │         │ MCP: element_add           │                            │     │
     │         ├───────────────────────────>│                            │     │
     │         │                            │  WebSocket: push           │     │
     │         │                            ├───────────────────────────>│     │
     │         │                            │                            │     │
     │ 实时看到AI添加的家具                                                    │
     │         │                            │                            │     │
     │         │                            │  WebSocket: user_move      │     │
     │         │                            │<───────────────────────────┤     │

     │                                                                         │
     │ 7.2 状态同步机制                                                        │
     │                                                                         │
     │ - Canvas State: 存储在 Web.Server 内存中（或 Redis）                    │
     │ - AI → Web: Canvas-MCP 操作后立即通过 WebSocket 推送                    │
     │ - Web → AI: 用户操作后，AI 可通过 canvas_get_changes 工具查询变更       │
     │                                                                         │
     │ 7.3 关键同步工具                                                        │
     │                                                                         │
     │ canvas_subscribe    // AI 订阅画布变更通知                              │
     │ canvas_get_changes  // AI 获取自上次查询后的变更列表                    │
     │ canvas_get_state    // AI 获取完整画布当前状态                          │

● 是的，当前 Polygon2D 不支持内环（holes）。

  从代码结构可以看出：

  public class Polygon2D
  {
      public Point2D[] Vertices { get; }  // 只有单一顶点数组
  }

  限制分析：

  | 方面      | 当前实现         | 支持内环需要
       |
  |---------|--------------|-----------------------------------------|
  | 数据结构    | 单一 Point2D[] | 外环 + 内环数组 Point2D[][] 或 Holes 属性
          |
  | JSON 格式 | [[x,y], ...] | { outer: [...], holes: [[...], [...]] } |
  | 几何计算    | 简单包围盒/中心点    | 需要排除内环面积
               |

  对项目的影响：

  根据 CLAUDE.md 中的数据模型，Polygon2D 用于：
  - rooms[].boundary - 房间边界
  - zones[].innerBoundary - 区域可用空间
  - zones[].exclusionAreas[].boundary - 禁区边界
  - modules[].bounds - 家具模块包围盒（4顶点矩形）

  当前设计用 exclusionAreas（禁区） 来处理不可布置区域，而非内环。这是一种替
  代方案：用独立的禁区多边形代替内环。

  是否需要支持内环？ 取决于实际场景：
  - 如果房间内有柱子/庭院需要精确表示 → 可能需要
  - 如果用 exclusionAreas 足够描述禁区 → 当前设计够用

  你有具体的使用场景需要内环支持吗？
